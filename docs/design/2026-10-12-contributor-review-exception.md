# Owner-approved contributor-review exception (#264)

Date: 2026-10-12. Status: active bounded exception ruling, linked from
[core/CONTRACT.md](../../core/CONTRACT.md#owner-approved-contributor-review-exception).

Only the mixed-authoring route confirmed by the owner's
[#264 ruling](https://github.com/feder-positronics/loop-zero/issues/264#issuecomment-6025584110)
and [scope confirmation](https://github.com/feder-positronics/loop-zero/issues/264#issuecomment-6031084292)
permits genuine native review by the less-writing family, with reduced
assurance rather than independence.

## Attribution and rewrite rules

- The squash commit uses a truthful `Co-Authored-By` trailer for the main
  contributing model.
- Disclose every minority writing model and its work in the commit body and a
  PR comment; label the PR narrative and comment
  **owner-approved contributor-review exception**.
- Only this route permits minority prose disclosure instead of trailers.
  Determine contributors from actual work, without calculated percentages or
  numerical minority thresholds; never manipulate attribution, invent a main
  author, silently discard credit or assume an automatic waiver.
- Before the first primary, this route may squash/rewrite, preserve truthful
  main attribution and full minority disclosure, then push for review.
  Merge-time squash cannot establish it.
- After primary review, the delta requires that exact primary as an ancestor:
  only unreviewed repairs may be rewritten where this disclosure route and
  truthful authorship permit; never credit someone else's repair to the main
  contributor.
- The selector, budget and all exact-head runner review, checks, findings,
  readiness and merge gates remain unchanged. Prose proves no permission.
  Outside the confirmed scope, retain all-writer trailers.
