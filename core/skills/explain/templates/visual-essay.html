A decision rationale · IntelFlo Architecture

The firehose, reimagined.

We're shifting from a pipeline that pushes every datafeed item into a user's inbox — to a model where users search the state of the knowledge on demand, and feeds deliver only the alerts and sources users have explicitly registered.

Reconstructed for review · 15 May 2026

01

The pivot, in one sentence.

Migrate IntelFlo's content pipeline from push-all-to-inbox to search-first. The primary surface for "what do we know about X?" becomes a unified search over the internal archive and external sources. Datafeeds still deliver — but only items matching a registered alert (saved search) or coming from a registered source subscription. Everything is still indexed for search.

The firehose is gone; the targeted delivery survives.

02

What the new model looks like.

In the old model, the system pushes everything and the user filters. In the new model, the user pulls what they need via search, while the inbox is reduced to what the user explicitly asked to be told.

03

04

What could go wrong.

Known Trust ranking is already a reopened blocker (#198 plus children #488–#491).

Likely Onboarding to "what to register" becomes the load-bearing UX moment — if users don't know what to register, the inbox underdelivers and they drift back to wanting the firehose.

Uncertain Migration sequencing; what happens to existing inbox content.

Speculative Long-term, the search layer becomes shared substrate for agent-driven synthesis.

05

Vocabulary.

Registered alert
A saved search the user wants to be notified about. Matches flow to inbox.
Registered source
A feed the user has explicitly subscribed to. New items flow to inbox.
Search layer
Unified query surface spanning internal archive + external sources.
Trust ranking
Ordering of heterogeneous results by relevance and credibility — the load-bearing hard problem.
The takeaway

Stop pushing everything. Let users pull what they need — and let feeds deliver only what they explicitly registered for. The hard work moves to trust ranking, which we were going to do anyway.
