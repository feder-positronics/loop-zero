Overview — what this template demonstrates

This file is a reference template, not a real briefing. Producers in the operational-slate register substitute their content into this shell; the CSS tokens, sticky bar, hero band, stat-card grid, and other affordances below are the SSoT vocabulary.

Producers: briefing (snapshot variants A–E) · grill-me (questionnaire mode) · resolve-findings (shortlist mode). All inherit the operational-slate palette from this template; no bespoke per-artifact palettes are permitted.
