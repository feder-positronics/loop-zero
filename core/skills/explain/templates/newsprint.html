Pipeline Architecture · Migration Brief

The firehose is over. Long live the registry.

A reconstructed rationale for moving IntelFlo's content pipeline from push-all-to-inbox to search-first delivery — and the trust-ranking question that decides whether it works.

By IntelFlo Architecture · Reconstructed for review · Verify before circulating

The decision

IntelFlo will migrate its content pipeline from a model that pushes every datafeed item into a user's inbox, to a model where users search the state of the knowledge on demand — and feeds drop new content into the inbox only for the alerts and sources users have explicitly registered.

The primary surface for the question "what do we know about X?" becomes a unified search layer that spans the internal IntelFlo archive and external sources such as OpenAlex and PubMed. Datafeeds continue to deliver new items to the inbox, but delivery is conditional: an item lands in the inbox only if it matches a registered alert (a saved search) or comes from a registered source subscription.

All new content is still indexed for search, regardless of whether it reaches the inbox. The archive remains complete; the inbox surface becomes scoped to declared user intent.

The firehose is gone. The targeted delivery survives.

Risks, in four labels

Known Trust ranking is already a reopened blocker (#198 + children #488–#491). It is the load-bearing implementation risk.

Likely Onboarding to "what to register" becomes the load-bearing UX moment. If users don't register meaningfully, the inbox underdelivers.

Uncertain Migration sequencing; transition handling for existing inbox content; mapping of implicit subscriptions to explicit registered alerts and sources.

Speculative Long-term, the search layer becomes shared substrate for agent-driven synthesis — compositional value, not yet validated.

Vocabulary

Registered alert
A saved search the user has chosen to be notified about; matches flow to the inbox.
Registered source
A feed the user has explicitly subscribed to; new items flow to the inbox.
Search layer
Unified query surface spanning the internal archive and external sources.
Trust ranking
Ordering heterogeneous results by relevance and credibility — the load-bearing hard problem.
— The takeaway —

Stop pushing everything; let users pull what they need via search, and let feeds deliver only what they've explicitly registered for. The hard work moves to trust ranking, which we were going to have to do anyway.
