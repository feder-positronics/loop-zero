Push-all → search-first.

Shift from a pipeline that pushes every datafeed item into a user's inbox, to a model where users search the state of the knowledge on demand — while feeds keep dropping new content into the inbox only for registered alerts and sources.

Decision

Hybrid · Option C

Search becomes primary. Inbox scoped to registered alerts (saved searches) and registered sources (feed subscriptions). Everything else is indexed for search but not pushed.
