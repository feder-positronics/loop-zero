Push-all → search-first

Shift the content pipeline from a model that pushes every datafeed item into a user's inbox, to a model where users search() the state of the knowledge on demand — while feeds keep dropping new content into the inbox only for registered alerts and sources.

Decision

tl;dr

Search becomes the primary surface for "what do we know about X?". Datafeeds still deliver — but only matched content for registered alerts (saved searches) and registered sources (feed subscriptions). Everything is still indexed for search.

Stop pushing everything; let users pull what they need via search — and let feeds deliver only what users explicitly registered for. The firehose is gone; the targeted delivery survives. The hard work moves to trust ranking — which was already on the path.
