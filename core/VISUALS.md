# Visual formats and channels

- **Steps, branches or states** → flowchart or state diagram.
- **3+ components, ownership or trust/data boundaries** → component or boundary diagram.
- **2+ options, trade-offs or before/after behaviors** → table or decision matrix.
- **Trends, proportions, latency/cost or counts over time** → chart or compact infographic.
- **UI layout, navigation, hierarchy or flow** → standalone [mockup](skills/design-mockup/SKILL.md)
  or annotated wireframe before coding. File every issue referring to a UI function with
  an annotated screenshot of the current UI and a mockup of any intended change.
  UI-changing PRs attach before/after (or expected vs. actual) screenshots.
- **Interactive owner chat** → render charts, infographics or HTML inline, or embed
  Mermaid/images. **GitHub** → use Mermaid or Markdown tables and embed a static
  PNG preview whenever linking a checked-in HTML mockup.
